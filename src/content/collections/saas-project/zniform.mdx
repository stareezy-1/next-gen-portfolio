ZniForm is a form builder with payments built in, created and operated solo as a personal SaaS. It was previously named Lyra.

## What it does

- Builds and publishes forms for registrations, orders, bookings, payment links, and digital products
- Launches secure **PayPal checkout** from the same public form link
- Reconciles payment status from authoritative PayPal capture events
- Generates PDF receipts and sends email or WhatsApp notifications
- Supports creator balances, withdrawals, workspaces, analytics, QR e-tickets, and door check-in
- Provides business integrations including API keys, webhooks, custom domains, memberships, and an embed/share kit

## Stack

Next.js and React · Hono on Cloudflare Workers · D1 and Drizzle · KV · R2 · Queues and Cron · Better Auth · PayPal Orders v2 · Tailwind CSS · Zustand · TanStack Query
